=========================================================
 FNF PS2 - compilar e enviar para o pendrive
=========================================================

Como usar: de dois cliques em COMPILAR.bat

Ele faz tudo: compila dentro do WSL e copia o jogo
completo para <pendrive>:\FNFPS2\. Nao apaga nada que ja
esteja no pendrive, entao os assets que voce baixou
continuam la.

A copia para o pendrive e' feita pelo WINDOWS (robocopy),
nao pelo Linux. O WSL so enxerga uma unidade do Windows se
o Windows a montar dentro dele; quando isso nao acontece,
o Linux nao consegue gravar no pendrive. O Windows sempre
consegue. Foi assim que uma versao anterior gravou o jogo
em C:\FNFPS2 por engano: nao acontece mais.

---------------------------------------------------------
 O QUE PRECISA ESTAR NO SEU PC
---------------------------------------------------------

1. WSL com Ubuntu 22.04, com o toolchain do PS2.

   Pelo que voce me disse, o ps2sdk esta em:
     \\wsl.localhost\Ubuntu-22.04\usr\local\ps2dev

   O script procura nesses lugares, nesta ordem:
     - a variavel PS2DEV, se estiver definida
     - /usr/local/ps2dev
     - ~/ps2dev
     - /opt/ps2dev

   Se o compilador estiver em outro lugar, edite o
   COMPILAR.bat e troque a linha:
     set "DISTRO=Ubuntu-22.04"

2. Um pendrive conectado. A letra e' descoberta sozinha:
   o programa pergunta ao Windows qual e' o volume
   REMOVIVEL. O disco C: nunca e' escolhido.

   Se a deteccao errar (acontece com HD externo, que o
   Windows nao chama de removivel), edite a linha:
     set "FORCAR=G:"
   e ponha a letra certa.

3. Se a pasta do WSL tiver nome diferente de Ubuntu-22.04,
   veja o nome certo com  wsl -l -v  e ajuste DISTRO=.

---------------------------------------------------------
 A PASTA ASSETS
---------------------------------------------------------

A pasta assets\ deste pacote tem 4 arquivos que o
compilador embute dentro do ELF:

    title_logoBumpin.lz4f
    title_gfDanceTitle.lz4f
    story_gf_idle.lz4f
    story_bf_idle.lz4f

Eles NAO estao no Git (sao megabytes de arte) e sem eles
o build nem comeca. Por isso vem juntos aqui. Se um dia
voce copiar so os fontes de outro lugar, o script avisa
exatamente quais estao faltando.

---------------------------------------------------------
 O QUE APARECE NA TELA
---------------------------------------------------------

  [1/5] conferindo o WSL
  [2/5] procurando o pendrive
  [3/5] convertendo o caminho do projeto
  [4/5] compilando dentro do WSL
  [5/5] copiando para <letra>:\FNFPS2

Depois do build vem o relatorio da suite de testes e o
tamanho do ELF; entao a copia e o que ficou no pendrive. Se algo der
errado, a janela NAO fecha sozinha: ela mostra o erro e
aponta o build.log, que e' o arquivo para me mandar.

A janela fica aberta no fim de proposito, senao o erro
passaria em um piscar de olhos.

---------------------------------------------------------
 DEPOIS DE COMPILAR
---------------------------------------------------------

No PS2:
   uLaunchELF -> mass:/FNFPS2/FNF_PS2.ELF

A pasta FNFPS2 TEM de estar na raiz do pendrive.
Se estiver dentro de outra pasta, o jogo dorme para
sempre e nao aparece nada na tela.

Se travar, me mande estes dois arquivos que o jogo
escreve no proprio pendrive:

   mass:/FNFPS2/BOOT.txt          ate onde o boot chegou
   mass:/FNFPS2/FNF_COLHEITA.txt  o log quadro a quadro

Eles sao a unica coisa que resolve o travamento: o mesmo
codigo roda mais de 1400 quadros no PC, entao o que falha
no console e' tempo de I/O ou sincronizacao, que nenhum
teste local consegue provar.

---------------------------------------------------------
 SE DER ERRO
---------------------------------------------------------

"o WSL nao esta instalado"
    PowerShell como administrador:
        wsl --install -d Ubuntu-22.04

"Nao achei a distribuicao ... no WSL"
    wsl -l -v   mostra o nome certo.
    Edite DISTRO= no COMPILAR.bat.

"Nao encontrei mips64r5900el-ps2-elf-gcc"
    O toolchain nao esta onde o script procurou.
    Rode dentro do WSL:
        ls /usr/local/ps2dev
    Se o compilador estiver em outro caminho:
        PS2DEV=/caminho tools/compilar_windows.sh

"NAO ACHEI O PENDRIVE"
    Nenhum volume removivel apareceu. Confira se o pendrive
    esta conectado e aparece no Explorador, e se ele nao
    esta' com a trava fisica de escrita ligada.
    Se for HD externo (o Windows nao chama de removivel) ou
    estiver em outra letra, edite no COMPILAR.bat:
        set "FORCAR=G:"

"A COPIA PARA O PENDRIVE FALHOU"
    O jogo compilou: ele esta' em build-out\ dentro desta
    pasta. Copie essa pasta a mao para <letra>:\FNFPS2.
    Se o Windows nao deixar gravar, o pendrive esta'
    protegido contra escrita ou cheio.

"a compilacao falhou"
    Veja build.log na pasta do projeto. Ele tem os
    primeiros erros do Makefile, nao a saida inteira.
